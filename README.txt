BEYOND PLUS SIZE — Complete HTML package v1.1.0

QUICK PREVIEW
Extract the ZIP and open combined.html in a modern browser.
This combined HTML includes styles, scripts and product data. Keep its assets folder alongside it.
Page navigation uses URL hashes so it works without a server.

STANDARD MULTI-PAGE PREVIEW
Run: python3 start-preview.py
Then open http://localhost:8080 in your browser.
The index.html and individual page folders use normal website routes.
Upload all package contents together to the root of an HTML hosting directory.

INCLUDED
Complete 147-route website, 98 products and catalogue variations, supplied Beyond logo,
optimized product galleries, CSS, JavaScript, product data and store data.

IMPORTANT
This is an HTML design and shopping preview, not an installable WordPress theme or plugin.
Cart, wishlist, fit profiles, addresses, reviews and demo orders are device-local.
Real login/OTP, payment, live orders, tax, shipping calculation and form submission require
WordPress/WooCommerce and the corresponding service integrations.
Women categories are included; the supplied catalogue contains men's products only.
Google Maps, WhatsApp and social links require an internet connection.

The live site has not been changed by creating this download.
